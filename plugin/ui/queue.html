Lists the repositories with open Renovate pull requests. Nothing selected = all repositories.

The key shows the number of open Renovate pull requests: green when all checks passed, yellow while checks run, red when a check failed. Press to browse the pull requests one by one, hold the key (0.6 s) to merge the one shown. Pull requests with merge conflicts are shown with a warning and are never merged. After 15 s without input the key returns to the summary.
